# CSE | CFES Experience

A personal reflection website documenting my experience with CSE and the Canadian Federation of Engineering Students (CFES). Built as a static multi-page site with plain HTML, CSS, and JavaScript.

## Pages

- `index.html` — home and about
- `favorite-moments.html` — photo highlights (`Images/`)
- `key-takeaways.html` — what I took away from the experience
- `reflection.html` — personal reflection
- `tips.html` — advice for others
- `feedback.html` — feedback form

## Structure

```
index.html            Home page
favorite-moments.html
key-takeaways.html
reflection.html
tips.html
feedback.html
styles.css            Shared styling
script.js             Shared interactions
Images/               Photos used across the site
```

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```
